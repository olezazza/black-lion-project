# Black Lion Rugby Club

A web application for managing and supporting a rugby club through a centralized online platform.

## About the Project

Black Lion Rugby Club is a web development project built to bring rugby-related information and community interaction into one place. It provides a platform where users can create accounts, manage profiles, share news, participate in discussions, and follow matches.

The project was developed as my **final project at TBC TechSchool**, as an opportunity to apply programming skills to a practical, full-stack web application.

## Features

- **User Authentication** — Account registration and login.
- **User Profiles** — Individual profiles for registered users.
- **News and Updates** — Publish and read club-related news.
- **Comments** — Interact with posts through comments.
- **Match Information** — View rugby match-related content.
- **Administration** — Administrative functionality for managing platform content.

## Technology Stack

- **Backend:** Python
- **Web Framework:** Flask
- **Database:** SQLite or the database configured in the project
- **Frontend:** HTML, CSS, JavaScript
- **Version Control:** Git and GitHub
